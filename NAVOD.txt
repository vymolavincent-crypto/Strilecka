NEONOVÝ NÁJEZD – jak hrát offline na mobilu
============================================

Na iPhonu musí hra jednou ležet na webové adrese, Safari si ji pak
uloží a jede i bez internetu. Zdarma přes GitHub Pages:

1) github.com → Sign up (zaregistrovat se).
2) + → New repository (nová složka) → název „hry“, Public → Create repository.
3) „uploading an existing file“ → přetáhni sem VŠECHNY soubory z tohoto ZIPu
   → Commit changes (uložit).
4) Settings (nastavení) → Pages → Branch: main → Save (uložit).
   Za minutu dostaneš adresu typu https://tvojejmeno.github.io/hry/
5) Otevři ji v Safari na iPhonu → Sdílet → Přidat na plochu.
6) Hotovo – ikona lodi na ploše, hra jede i bez internetu.

Když hru později aktualizuješ, nahraj nové soubory a v sw.js
zvyš číslo verze (neon-najezd-v3 → v4).
